# How to run StreamlineCloud
A quick guide

### Choose your start file
If you are on Linux or Windows, 
select the streamlinecloud-launcher-LINUX 
or -WIN executable, 
if you are on an ARM-based system, 
use the version with ARM. 
Otherwise, you can use the .jar file 
but make sure you have java installed.
**The unecessary files will be deleted automatically!**

### Linux
Open a terminal and type the following commands
 ```shell
 chmod <yourfile>
 ```  
 ```shell
 ./<yourfile>
 ```  

### Windows
Just double-click the .exe file. 
You may need to run it as an administrator.

### Java
Make sure you have java installed and use the command
 ```shell
 java -jar <yourfile>
 ```
